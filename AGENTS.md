# Project Instructions for AI Agents

## Writing & Formatting Rules

- **No em-dashes anywhere in the project:** Do not use the em-dash character (`U+2014`) in any file in this repository, including Python source code, comments, docstrings, Jupyter notebooks, Markdown documents, LaTeX files, plot labels, presentations, or commit messages.
- **Approved alternatives:** Use commas, parentheses, colons, semicolons, periods, or standard hyphens (`-`) / LaTeX en-dashes (`--`) instead.
